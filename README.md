# LuminDub

منصة دبلجة فيديو بالذكاء الاصطناعي: ارفع فيديو واحداً واحصل على نسخ مدبلجة بالدارجة المغربية، العامية المصرية، اللهجة الخليجية، الفرنسية والإنجليزية.

## كيف تعمل

```
فيديو → ffmpeg (استخراج الصوت) → Whisper عبر Groq (نسخ + أزمنة)
      → Gemini (ترجمة بالمعنى + تكييف ثقافي بلهجة الهدف)
      → Edge TTS (أصوات عصبية مجانية) → pydub (مزامنة التوقيت)
      → ffmpeg (دمج الصوت الجديد مع الفيديو)
```

## الأدوات المجانية المستخدمة

| المهمة | الأداة | ملاحظة |
|---|---|---|
| الاستضافة | Render (Docker, free) | تنام بعد 15 دقيقة، وتستيقظ في نحو دقيقة |
| الكود | GitHub | |
| النسخ الصوتي | Groq (whisper-large-v3-turbo) | مفتاح مجاني من console.groq.com |
| الترجمة | Google Gemini API | مفتاح مجاني من aistudio.google.com |
| الصوت | edge-tts | بدون مفتاح |

## التشغيل محلياً

```bash
# يلزم تثبيت ffmpeg
pip install -r requirements.txt
cp .env.example .env   # ضع المفاتيح
export $(cat .env | xargs)
uvicorn app.main:app --reload
```
ثم افتح http://localhost:8000

## النشر على Render

1. ارفع المجلد إلى مستودع GitHub.
2. في Render: New → Blueprint (أو Web Service) واختر المستودع. سيقرأ `render.yaml`.
3. أضف متغيري البيئة `GROQ_API_KEY` و `GEMINI_API_KEY`.
4. انتظر البناء، ثم افتح الرابط.

## حدود النسخة المجانية

- الحد الأقصى 50MB و180 ثانية لكل فيديو.
- المهام والملفات في الذاكرة وقرص مؤقت: تُحذف بعد ساعة أو عند إعادة تشغيل الخدمة.
- معالجة لغة واحدة في المرة (تسلسلية) لتناسب 512MB RAM.
- الأصوات جاهزة وليست مستنسخة من صوت المتحدث.
- لا يوجد Lip-sync في هذه النسخة.
- أصوات Edge TTS المغربية والمصرية والخليجية فصحى الإيقاع نسبياً، والنص هو الذي يحمل اللهجة.

## خارطة الطريق

1. استنساخ الصوت (XTTS / OpenVoice على GPU مدفوع أو Replicate).
2. Lip-sync (Wav2Lip / LatentSync) كميزة مدفوعة.
3. قائمة انتظار (Redis) وتخزين خارجي (R2/S3) بدل الذاكرة.
4. حسابات مستخدمين، دفع، ونشر مباشر إلى يوتيوب وتيك توك.
5. محرر نص الترجمة قبل التوليد النهائي.

## الاستخدام المسؤول

يُشترط إقرار المستخدم بملكية الفيديو أو الإذن بدبلجته. عند إضافة استنساخ الصوت، يجب التحقق من موافقة صاحب الصوت.
